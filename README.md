## ✨ Fonctionnalités

- **Galeries thématiques** (séries de terrain, monuments, noir et blanc…) avec visionneuse plein écran
- **Images optimisées pour le web**, deux tailles par photo (miniature et grand format)
- **Design responsive** : téléphone, tablette, ordinateur
- **Contacts configurables** (e-mail, Instagram, WhatsApp) : les boutons n'apparaissent que si l'information est renseignée
- Balises Open Graph pour un bel aperçu lors du partage du lien
- Site statique sans dépendance, déployé sur **Vercel**
